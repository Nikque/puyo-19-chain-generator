# ぷよぷよ19連鎖盤面ジェネレーター

[English README](README.en.md)

空の盤面から、4色または5色を使った19連鎖盤面をランダムに生成するC++20のコンソールプログラムです。成功した盤面のURLを `19chain_urls.txt` に追記します。このプログラムは独立したプロジェクトとしてMITライセンスで公開しています。

## 動作

- フィールドは6列×13段です。13段目のぷよは落下しますが、連結と消去の判定には参加しません。
- 消去は19回起こり、各回で同じ色の連結成分が1組だけ、ちょうど4個消える盤面を採用します。
- 空盤面を連鎖後の状態と見立て、4個の消去を逆方向に追加するビーム探索を使います。完成時に19連鎖を再計算します。
- 最初の発火グループには、上のぷよが1個以下の位置が少なくとも1つ必要です。3列目の12・13段目も指定の条件で検査します。
- 2個組を重力に沿って積める順序を探索し、最後の1組が発火グループに触れることを確認します。
- 同じURLは今回の実行中も過去の `19chain_urls.txt` に対しても除外します。

ペアの配置順序は確認しますが、ゲーム中の左右移動・回転キー入力の経路まではシミュレーションしません。おじゃまぷよも扱いません。

## ビルド

Visual Studio 2022など、C++20対応のコンパイラとCMake 3.16以降が必要です。PowerShellで次を実行します。

```powershell
cmake -S . -B build
cmake --build build --config Release
cd build/Release
.\random_19_chain.exe
```

Visual StudioのCMakeプロジェクトとして、このフォルダーを開いてビルドすることもできます。ビルド時に `config.ini` が実行ファイルの隣へコピーされます。上の `build/Release` はVisual Studioジェネレーターの場合の例です。別のジェネレーターでは実行ファイルのあるフォルダーへ移動してください。

## 設定と出力

実行前に、実行ファイルの隣にある `config.ini` を編集します。各項目には日本語の説明コメントがあります。

| 項目 | 意味 |
| --- | --- |
| `target_success_count` | この実行で新たに保存する、重複のない盤面の目標数 |
| `initial_seed` | 乱数の初期値。同じ設定なら探索順を再現できます |
| `color_count` | 通常ぷよの色数。4または5 |
| `beam_width` | 各連鎖段階で残す盤面の最大数 |
| `restarts` | 探索の最大試行回数。1試行から保存する盤面は最大1つ |
| `candidates_per_parent` | 1つの親盤面から次の段階へ残す候補数 |

目標に届く前に `restarts` に達した場合、生成済みURLは残して終了します。成功数を増やしたいときは、`restarts` を目標数より十分大きくし、`beam_width` と `candidates_per_parent` を段階的に増やしてください。色数や `initial_seed` を変えると別の探索になります。幅を増やすと処理時間とメモリ使用量も増えます。

URLは**実行時の作業フォルダー**の `19chain_urls.txt` に1行ずつ追記されます。既存ファイルのURLは重複判定に使い、`target_success_count` には数えません。コンソールには盤面、発火位置、2個組の配置順序、探索の進捗を表示します。
